Desk Watch blocker

…

Desk Watch must be open. It asks "Connect?" in its window: click Allow.

Use a pairing code instead

Only if the Allow question does not appear. The code is in Desk Watch → Settings → Blocker mode.

This extension sends the address of your active tab only to the Desk Watch app on this computer (127.0.0.1), and only to decide whether to block it during a study session. Nothing goes to the internet.
